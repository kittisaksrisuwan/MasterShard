# MasterShard

Synchronizes metadata for large datasets across multiple storage systems with a simple web interface.

MasterShard is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Synchronizes metadata for large datasets
- across multiple storage systems with
- a simple web interface

## Key Features

- Synchronizes metadata for large datasets
- across multiple storage systems with
- a simple web interface

## Technology Stack

- rust
- rust framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/MasterShard.git`
2. `cd MasterShard`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
